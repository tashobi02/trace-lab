# Repository scope

Trace Lab is an experimental notebook workspace for trace conditioning and model-mediated rewards in reinforcement learning. The initial implementation supplies portable configuration, preserved runtime records, an isolated notebook controller, environment inspection and offline restoration.

Model scoring, Unity execution, reward reconstruction, PPO training, baseline analysis and trace exports are planned subsequent capabilities. The earlier verified research results are not represented as newly executed notebook experiments. Forward/reverse/constant target values and timing remain research design decisions.

All maintained executable source in this repository is `.ipynb`; configuration/evidence stays YAML/JSON, and prose stays Markdown. Upstream software and installed libraries retain their original formats and attribution. Original sealed evidence remains outside this clone and unchanged. The existing MIT license is preserved.
